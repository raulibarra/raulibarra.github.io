Slippery Logs

Backend-Integrated Infinite Jumper with Anti-Cheat Systems
Focus: Backend Integration & Security
Tech: Unity, C#, PlayFab, Node.js
What I Built:
  • Secure Backend Architecture: Integrated PlayFab with custom cloud functions for anti-cheat score validation, ensuring authentic leaderboard data through server-side verification after every set number of jumps.
  • Infinite Procedural Generation: Developed scalable log spawning systems with object pooling for collectibles and obstacles, maintaining smooth performance during extended gameplay sessions.
  • Dynamic Remote Configuration: Implemented PlayFab-driven remote parameters for difficulty tuning, score multipliers, and localization data, allowing real-time game balance adjustments without updates.
  • Complete UI/UX Systems: Designed and programmed all game screens with integrated leaderboards, player progression tracking, and responsive energy management systems.

Features original soundtrack and sound design with optimized audio management for enhanced player experience.

Skills Demonstrated: Backend services integration, anti-cheat implementation, cloud functions development, and full-stack game architecture.
