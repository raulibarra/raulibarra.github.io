Crushers!

Casual Match-3 Multiplayer PVP Game with RPG Elements
Role: Senior Game Developer (Contractor)
Company: Redemption Games Inc.
Team Size:10+ including 6 devs
Tech: Unity, C#, Photon Quantum, Firebase
Key Contributions:
  • Core Gameplay Features: Prototyped key systems like Home panel tabs, Post Level Win/Lose sequences, and the Trophy Road progression system. These prototypes helped shape the core game mechanics.
  • Shared Libraries: Built reusable systems for UI management, asset retrieval, and object pooling that improved development efficiency across multiple projects.
  • Data-Driven Configuration: Implemented game configuration systems for Trophy Road and the main Core-Loop with seamless backend synchronization. Used the same approach for in-game items and store products.
  • Tutorial System: Created a flexible, event-driven tutorial system with JSON-based remote updates. It supported custom actions, checkpoints, and persistence so players could resume tutorials if they left mid-session.
  • Audio Framework: Developed a robust audio system with SFX variations, randomization, ducking, and dynamic AudioMixer presets that adapted to different game states.
  • Monetization Features: Prototyped GoldRush, Season Pass, and Weekly Events features to boost player engagement and revenue streams.
