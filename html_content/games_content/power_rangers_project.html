Power Rangers - Morphin Legends

Turn-Based RPG with Data-Driven Systems
Role: Senior Game Developer
Company: Globant
Team Size: 15+ including 7 devs
Tech: Unity, C#, Data-Driven Architecture
Key Contributions:
  • Abilities System Refactor: Took the existing prototype abilities system and restructured it for better code reusability and proper separation of responsibilities. Made it fully unit testable with a data-driven architecture.
  • Tutorial System: Built an event-driven tutorial system that listened to player actions and dynamically triggered tutorials. It had checkpoint persistence so players could resume if they left mid-session.
  • Dynamic Audio System: Created an impact SFX system that dynamically selected sound effects based on what weapon was used (sword, fists) and what material it hit (flesh, rock). Really improved the combat feel.
  • Music Composition: Composed and implemented original music inspired by 90's TV show soundtracks, which added that authentic nostalgic atmosphere the game needed.
  • Core Game Features: Built the heroes collection system, dialogue system, PVP mechanics, and store system to round out the complete gameplay experience.
