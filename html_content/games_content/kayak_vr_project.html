Kayak VR Experience

Immersive VR Simulator with Spatial Audio
Role: Game Developer
Company: Utopic Studio Spa
Team Size:5 including 2 devs
Tech: Unity, Google Cardboard, C#, Steam Audio
Key Contributions:
  • Infinite Scrolling System: Built a dynamic map generation system using weighted pre-built scenery pieces that spawned based on how far the player had traveled. The kayak moved along spline paths through the terrain.
  • Procedural Content: Implemented grid-based obstacle placement and built custom editor tools to help with level design and content management.
  • Spatial Audio Programming: Integrated Steam Audio for binaural spatialization and added custom distance-based priority systems for AudioSources to optimize performance.
  • Dynamic Audio Systems: Created 2D waterfall audio with distance-based volume control and built custom inspectors for real-time audio debugging during development.
  • VR Optimization: Ensured smooth VR performance for Google Cardboard with efficient rendering and audio processing optimized for mobile hardware.
  • Sound Design: Composed and implemented all the sound effects for the VR kayaking experience.
