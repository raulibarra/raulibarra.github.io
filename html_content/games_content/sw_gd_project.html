StarWars Galactic Defense

Tower Defense with Advanced Optimization Systems
Role: Senior Game Developer
Company: DeNa Santiago
Team Size: 60+ including 8 devs
Tech: Unity, C#, Custom Shaders, ETC Compression
Key Contributions:
  • Data-Driven Abilities System: Expanded the complex abilities system for towers and characters to include instant stat changes, status effects, and area-of-effect mechanics like healing fountains and lava zones.
  • Android Optimization: Reduced the game size by 35% using ETC compression for transparent textures. Built a custom pipeline that split textures into RGB and Alpha channels and recombined them at runtime with shaders.
  • Performance Engineering: Optimized memory usage and improved performance on older OpenGL 2.0 devices through custom texture compression and rendering techniques.
  • Editor Tools Development: Built a comprehensive editor suite including a map editor, UI skinning system, and HotReload with real-time stats debugging for designers.
  • Audio System Architecture: Developed a custom audio system with separate music/SFX controls, audio prioritization, and ducking features. This was before Unity had AudioMixer.
  • Social Features: Integrated Facebook friend requests and energy-sharing systems to enhance player engagement and retention.
